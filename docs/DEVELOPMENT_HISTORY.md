# uskSpriteSheetMaker 開発履歴（過去の変更メモ）

画像ファイルを並べ、PNG / TGA のスプライトシートとアニメーションGIFを作成する
.NET Framework 4.8向けWinFormsアプリです。

アプリ名と実行ファイル名を `uskSpriteSheetMaker` に統一し（旧名 SpriteMakerUntukAnjing。設定フォルダは初回起動時に自動で引き継ぐ）、3×3のセルに再生ボタンを重ねたアイコン（ユーザー作成のモックアップを元にした透過アイコン）を採用しています。

## キャラクター／エフェクト動作プレビュー

- 「対象」横のenumから「デフォルト」「エフェクト」「キャラクター」を切り替え
- 右側を「プレビュー」「状態遷移」「パラメーター」の3タブへ分離し、プレビュー内には設定項目を表示しない
- デフォルト／エフェクト／キャラクターの対象選択をプレビュー上から外し、「状態遷移」ページ最上段へ配置
- 「状態遷移」は各状態を縦一覧で表示し、使用／未使用、開始セル、終了セルを編集
- FPSは状態ごとに持たず、「パラメーター」の共通FPSから全種類・全状態を一括制御
- デフォルトのパラメーターは共通FPS、キャラクターは共通FPS・速度・ジャンプ力・重力・接地オフセット・逆側反転、エフェクトは共通FPS・速度
- デフォルトでは従来どおり開始セル、終了セルを指定して単体フレームを再生
- 固定640×360比率の2D空間と、画面高5%の仮ピンク色足場で挙動を確認
- スプライト表示高をステージ比率から算出し、元画像の解像度に関係なく一定比率で表示
- 動作プレビューは640×360のステージ座標を維持しつつ元スプライトを直接描画し、中間合成による解像度低下を防止
- パラメーターの共通項目は「FPS」「背景」「黒透過」「カラー」として、デフォルト／キャラクター／エフェクトのすべてで表示
- パラメーター内へ「基本設定」「加工」ヘッダーを追加し、FPS・背景を基本設定、黒透過・カラーを加工として整理
- 「背景」から、既定グレー／ブルーグレー／ウォームグレーの低彩度な市松背景を選択
- 「黒透過」を有効にすると、加算合成向けの黒背景素材を色味を保った通常アルファへ変換（元画像は変更しない）
- 黒透過の再計算中と完了後700msはチェックを無効化し、連打やクリックの多重処理を防止
- 「カラー」からUnity風の四角い彩度・明度ピッカーとHueバーを開き、全フォルダ・全画像を一括調整
- カラー調整ボタンの左側へ現在色のスウォッチを常時表示し、右側には乗算／加算方式を簡潔に表示
- カラー合成は「乗算」「加算」を選択でき、強さ0～100%とHEX値を編集可能。元画像のアルファは保持
- ピッカー操作はリアルタイム反映し、16msの更新集約、旧処理のキャンセル、単一処理キューで高速ドラッグ時の多重実行を防止
- 色処理を縮小・黒透過後の共通画像パイプラインへ統合し、シート／動作プレビューとPNG・TGA・GIF出力を同じ画素処理に統一
- 乗算／加算 × 黒透過ON/OFFの全組み合わせでPNG・TGA・GIFを実出力・再読込し、アルファとプレビュー画素の一致を検証
- カラー再計算中は出力操作を一時的に無効化し、更新前のプレビューを誤って書き出すことを防止
- 入力、状態管理、フレーム再生、エフェクト移動を別クラスに分離
- キャラクターはIdle（待機）、右・左・上・下移動、左右ジャンプ、左右それぞれの攻撃1〜2を設定可能
- 右移動または左移動の片側だけが設定されている場合は、そのアニメーションを両方向で使用
- 左右移動で向きを保持し、攻撃は現在向いている側の攻撃1または2を再生
- 「逆側反転」が有効なら不足している移動・攻撃方向を水平反転。両側が設定済みなら反転しない
- Jumpは右向き・左向きそれぞれを「踏み込み」「滞空」「着地」の3段階に分割
- ジャンプの片側や段階が未設定なら設定済みの段階を代替し、「逆側反転」が有効なら反対向きの代替を水平反転
- 各状態に使用／未使用、開始セル、終了セルを設定
- 開始・終了セル入力は空欄から打ち直せる3桁幅とし、編集中は空欄や未確定文字を維持。フォーカス移動またはEnterで1～999へ補正
- 速度・ジャンプ力・重力は`1.0`基準のステージ倍率で指定
- 接地オフセットは画像ピクセル単位（-128〜128、既定0）。スプライトが画像中央に描かれ足元に透明余白がある場合に、プラスにするとキャラを下へずらして足を足場に接地させる（見た目の描画位置のみ。ジャンプ等の挙動は変わらない）
- 初期キーはA/Dで左右、W/Sで上下、Spaceでジャンプ、G/Rで攻撃1〜2（Fは全体表示ショートカット用）
- 状態遷移の各行にキーバインドを表示し、クリック後の次のキーまたはマウスボタンで変更。重複割り当ては自動解除
- 名前・数値入力中とウィンドウ非アクティブ時は入力状態を解除し、誤操作を防止
- エフェクトは開始／終了、方向X/Y、共通FPS、移動速度を設定して単体再生
- エフェクトが画面外へ出た場合は中央から再開
- 左シートの割り当て済みセルを色分け表示
  - Idle: 緑
  - 右・左・上・下移動: 赤
  - 左右Jump（踏み込み／滞空／着地）: 黄
  - Attack 1〜2: 青
  - Effect: 紫
- 状態範囲、物理パラメータ、キー設定、プレビュー種別もCtrl+Zの復元対象
- DPIとモニターの作業領域に応じて最低ウィンドウサイズを設定し、状態名や入力欄の潰れを防止

## 基本操作

1. 画像または画像入りフォルダを左側へドロップします。
2. 横セル数、縮小率、FPS、再生範囲を設定します。
3. PNG / TGA / GIF ボタンから保存します。

対応入力: PNG / JPG / JPEG / BMP

プレビュー: マウスホイールで5%刻みズーム、左ドラッグで移動、
ダブルクリック・0キーで全体表示へ戻ります。Fキーは、シートまたはプレビューを最後にクリックしていればその表示を中心・全体表示（100%）へ戻し、それ以外の場所を最後にクリックしている間は何もしません。

## 大きな画像・大きなシートの扱い

- 64bit（AnyCPU）で動作。メモリを大きく使える
- PNG / TGA は、シート全体を1枚のビットマップにせず、上から数行ぶんずつ作ってファイルへ流し込む。GDI+の約1GBの上限を超える大きさ（例: 24,000 × 24,000 px）でも書き出せる。
- 書き出しは別スレッドで行い、状態欄に進み具合（%）を表示。`Esc` で中止でき、書きかけのファイルは残さず、同名の既存ファイルも壊さない（完成まで `.part` で書き、最後に置き換える）
- TGA は規格上、幅・高さとも 65,535 px まで（超えるときは PNG を案内）。GIF も 1コマ 65,535 px まで。PNG は事実上制限なし
- 画像の合計が大きいときは、プレビューだけを自動で縮小して読み込む（状態欄に「プレビューは 1/N に縮小」と表示）。シートの大きさ・セルの座標・メモの位置・書き出しは原寸のまま
- 読み込んだ元画像のキャッシュは合計 256MB までで、古いものから捨てる
